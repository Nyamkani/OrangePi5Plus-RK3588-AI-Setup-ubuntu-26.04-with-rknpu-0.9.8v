# 06. Post-install Issues / 설치 후 이슈

## 한국어

## 1. custom kernel headers dependency 문제

처음에는 다음 package도 같이 설치했습니다.

```text
linux-headers-6.1.0-1025-73400e-rockchip
```

이 package는 다음 common headers package를 요구했습니다.

```text
linux-rockchip-headers-6.1.0-1025-73400e
```

하지만 `binary-rockchip` 결과에는 해당 common headers package가 없어서 이후 apt 작업에서 다음 오류가 발생했습니다.

```text
Unsatisfied dependencies:
linux-headers-6.1.0-1025-73400e-rockchip :
Depends: linux-rockchip-headers-6.1.0-1025-73400e
but it is not installable
```

해결:

```bash
sudo dpkg -r linux-headers-6.1.0-1025-73400e-rockchip
sudo apt --fix-broken install
```

### 결론

RKNN/RKLLM runtime 사용에는 custom kernel headers가 필요하지 않습니다.

따라서 재설치 시:

```text
install:
- linux-image
- linux-modules
- linux-modules-extra

skip unless needed:
- linux-headers
```

로 두는 것이 단순합니다.

## 2. dmesg에서 보였지만 fatal이 아니었던 메시지

새 kernel에서 RKNPU probe 중 다음과 같은 메시지가 보였습니다.

```text
can't request region for resource ...
Failed to create debugfs directory
debugfs: Directory ... already present!
```

하지만 바로 이어서:

```text
[drm] Initialized rknpu 0.9.8 20240828 for fdab0000.npu on minor 1
```

가 확인되었고:

```bash
sudo cat /sys/kernel/debug/rknpu/version
```

결과도:

```text
RKNPU driver: v0.9.8
```

였습니다.

따라서 해당 메시지들은 이 시스템에서는 RKNPU probe 실패를 의미하지 않았습니다.

---

## English

The custom flavour header package depended on a common package that had not been generated by the chosen packaging target.

This left apt with an unmet dependency.

The practical fix was to remove only the custom flavour header package and repair apt:

```bash
sudo dpkg -r linux-headers-6.1.0-1025-73400e-rockchip
sudo apt --fix-broken install
```

The image/modules remained installed and the running kernel was unaffected.

Kernel headers are not required for RKNN/RKLLM inference.
